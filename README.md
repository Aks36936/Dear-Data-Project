# Dear Data — Daily Calorie Burn Visualisation

# Overview

This project explores how everyday activities affect the number of calories I burn throughout the day. As part of the Dear Data project, I will collect data from my surroundings and use Java to create a visual representation of my findings.

The aim is to understand how different activities contribute to my daily calorie expenditure and identify patterns in my activity levels.

# Data Collection

I will record my estimated calories burned throughout the day and track the activities that contribute to my total.

Examples of activities include:
- Walking
- Playing football
- Going to the gym
- Running
- Other everyday activities such as sitting down...

For each day, I will record the total calories burned and the activities that contributed to  this amount.


Using Java, I will develop a visual display that represents the collected data in a creative and informative way.

The visualisation will aim to:
- Show daily calorie expenditure.
- Represent the different activities that contribute to the total.
- Display patterns in my daily activity through visual elements such as colours, shapes and symbols.




The goal of this project is to turn everyday personal data into a visual story. By exploring the relationship between my daily activities and estimated calories burned, I hope to communicate my findings in a way that is both visually engaging and easy to understand.
